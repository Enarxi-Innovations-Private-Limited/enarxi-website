## 🔥 Firestore Data Model

**Collection**: `teamMembers`

**Document Structure**:
```javascript
{
  id: string,              // Auto-generated by Firestore
  name: string,            // Employee name
  role: string,            // Job title
  images: [                // Array of images
    {
      format: "jpg",       // Image format
      height: 1000,        // Image height in pixels
      width: 800,          // Image width in pixels
      publicId: "enarxi/our_team/john_doe",  // Cloudinary public ID
      url: "https://res.cloudinary.com/..."  // Full Cloudinary URL
    }
  ],
  visibility: true,        // Boolean (shown on website)
  createdAt: Timestamp,    // Server timestamp
  updatedAt: Timestamp,    // Server timestamp
  order: 0                 // Numeric order for sorting
}
```

**Required Indexes**:
1. Composite index: `order` (asc) + `__name__` (asc)
2. Optional: `visibility` (asc) + `order` (asc) for public queries

## 🚀 How to Use

### 1. Setup Environment
```bash
# Add to .env
VITE_CLOUDINARY_UPLOAD_PRESET_OUR_TEAM=enarxi_our_team

# Restart dev server
npm run dev
```

### 2. Configure Cloudinary
- Go to Cloudinary Console → Settings → Upload
- Create unsigned upload preset: `enarxi_our_team`
- Set folder: `enarxi/our_team` (optional)

### 3. Access Admin Portal
- Navigate to Admin Portal
- Click "Our Team" in sidebar
- Click "+ Add New" to add first team member

### 4. Add Team Member
- Upload image (will auto-crop if not 4:5)
- Fill in name and role
- Toggle visibility if needed
- Click "Add Member"

### 5. Manage Team
- **Reorder**: Drag rows using six-dot handle
- **Edit**: Click Edit button, modify, save
- **Toggle Visibility**: Click eye icon
- **Delete**: Click Delete, confirm (atomic deletion)

## 💡 Tips

- **Order field**: New members get `order = existingMembersCount`, so they appear at the end
- **Atomic deletion**: Always deletes from Cloudinary first to prevent orphaned images
- **Real-time updates**: Uses `onSnapshot` so changes reflect immediately across all clients
- **Image optimization**: Use Cloudinary transformations on frontend for best performance
- **Aspect ratio**: 4:5 is ideal for portrait photos (800x1000, 400x500, etc.)
