================================================================================
🔴 URGENT FIX REQUIRED: Firebase Permission Error
================================================================================

ERROR YOU'RE SEEING:
"Admin verification error: 7 PERMISSION_DENIED: Missing or insufficient permissions"

CAUSE:
Your Firebase service account doesn't have permission to access Firestore.

================================================================================
🔧 QUICK FIX (5 MINUTES)
================================================================================

METHOD 1: Grant IAM Permissions (RECOMMENDED)
----------------------------------------------

1. Go to: https://console.cloud.google.com/iam-admin/iam

2. Select your Firebase project from dropdown

3. Find your service account email (check backend/.env for FIREBASE_CLIENT_EMAIL)
   It looks like: firebase-adminsdk-xxxxx@your-project.iam.gserviceaccount.com

4. Click the pencil icon (✏️) next to it

5. Click "+ ADD ANOTHER ROLE"

6. Add these roles:
   ✅ Cloud Datastore User
   ✅ Firebase Admin SDK Administrator Service Agent

7. Click "SAVE"

8. Wait 1-2 minutes

9. Restart your backend:
   - Stop backend (Ctrl+C)
   - Run: npm start

10. Test again from frontend

METHOD 2: Generate New Service Account Key (IF METHOD 1 FAILS)
---------------------------------------------------------------

1. Go to: https://console.firebase.google.com/

2. Select your project

3. Click gear icon → Project Settings

4. Go to "Service Accounts" tab

5. Click "Generate New Private Key" button

6. Download the JSON file

7. Open the JSON file and update backend/.env:
   
   FIREBASE_PROJECT_ID=<copy from "project_id" in JSON>
   FIREBASE_PRIVATE_KEY="<copy from "private_key" in JSON - KEEP THE \n!>"
   FIREBASE_CLIENT_EMAIL=<copy from "client_email" in JSON>

   IMPORTANT: 
   - Keep quotes around FIREBASE_PRIVATE_KEY
   - Don't remove \n characters from private key
   - Copy exactly as shown in JSON

8. Save backend/.env

9. Restart backend:
   cd backend
   npm start

10. Test again from frontend

================================================================================
📋 VERIFY YOUR .env FILE
================================================================================

Your backend/.env should look like this:

PORT=5000
NODE_ENV=development

# These three values come from Firebase service account JSON
FIREBASE_PROJECT_ID=your-project-id
FIREBASE_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----\nMIIEvQIBADANBgkqhkiG9w0BAQE...(very long)...\n-----END PRIVATE KEY-----\n"
FIREBASE_CLIENT_EMAIL=firebase-adminsdk-xxxxx@your-project.iam.gserviceaccount.com

CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_api_key
CLOUDINARY_API_SECRET=your_api_secret

FRONTEND_URL=http://localhost:3001

JWT_SECRET=your_random_secret

RATE_LIMIT_WINDOW_MS=900000
RATE_LIMIT_MAX_REQUESTS=100

COMMON MISTAKES TO AVOID:
❌ Missing quotes around FIREBASE_PRIVATE_KEY
❌ Removed \n characters from private key
❌ Extra spaces before/after = sign
❌ Wrong project ID
❌ Old/revoked service account key

================================================================================
🐛 STILL NOT WORKING?
================================================================================

If you still get errors after trying both methods:

1. Check Firebase Console → Project Settings → Service Accounts
   - Make sure "Firebase Admin SDK" section exists
   - Verify your service account is listed

2. Verify .env file:
   - No syntax errors
   - All values filled in
   - Private key has \n characters
   - Quotes around private key

3. Check IAM permissions:
   - Service account has "Cloud Datastore User" role
   - Service account has "Firebase Admin" role

4. Try these commands:
   cd backend
   rm -rf node_modules
   npm install
   npm start

5. Generate a COMPLETELY NEW service account:
   - Firebase Console → Project Settings → Service Accounts
   - Click "Manage service account permissions"
   - Create new service account
   - Grant it Firebase Admin role
   - Generate key
   - Update .env
