================================================================================
QUICK START GUIDE - Enarxi Backend Setup
================================================================================

Follow these steps to get your secure backend running in 10 minutes!

================================================================================
STEP 1: INSTALL BACKEND DEPENDENCIES (2 minutes)
================================================================================

Open terminal in the project root and run:

    cd backend
    npm install

Wait for installation to complete...

================================================================================
STEP 2: GET FIREBASE CREDENTIALS (3 minutes)
================================================================================

1. Go to: https://console.firebase.google.com/
2. Select your project
3. Click gear icon → Project Settings
4. Go to "Service Accounts" tab
5. Click "Generate New Private Key" button
6. Download the JSON file

Keep this file SECURE! Don't share it or commit it to git.

================================================================================
STEP 3: CREATE BACKEND .env FILE (3 minutes)
================================================================================

In the backend folder:

1. Copy .env.example to .env:
   
   Windows: copy .env.example .env
   Mac/Linux: cp .env.example .env

2. Open backend/.env in your text editor

3. Fill in Firebase values from the JSON file you downloaded:

   FIREBASE_PROJECT_ID=your-project-id
   FIREBASE_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----\nYour_Key_Here\n-----END PRIVATE KEY-----\n"
   FIREBASE_CLIENT_EMAIL=firebase-adminsdk-xxxxx@your-project.iam.gserviceaccount.com

   IMPORTANT: Keep the quotes around FIREBASE_PRIVATE_KEY!

4. Fill in Cloudinary values (from https://cloudinary.com/console):

   CLOUDINARY_CLOUD_NAME=your_cloud_name
   CLOUDINARY_API_KEY=your_api_key
   CLOUDINARY_API_SECRET=your_api_secret

5. Set frontend URL:

   FRONTEND_URL=http://localhost:3001

6. Save the file!

================================================================================
STEP 4: UPDATE FRONTEND .env FILE (1 minute)
================================================================================

In your main project .env file (not backend/.env):

1. Add this line:

   VITE_API_BASE_URL=http://localhost:5000/api

2. REMOVE this line if it exists:

   VITE_CLOUDINARY_API_SECRET=...  ❌ DELETE THIS LINE!

3. Save the file!

================================================================================
STEP 5: START BACKEND SERVER (1 minute)
================================================================================

In the backend folder, run:

    npm start

You should see:

    ═══════════════════════════════════════════════════════════
    🚀 Enarxi Backend API Server
    ═══════════════════════════════════════════════════════════
    📡 Server running on: http://localhost:5000
    🌍 Environment: development
    🔒 CORS enabled for: http://localhost:3001

If you see this, SUCCESS! ✅

================================================================================
STEP 6: START FRONTEND (1 minute)
================================================================================

Open a NEW terminal in the project root and run:

    npm run dev

Your frontend should start on http://localhost:3001

================================================================================
STEP 7: TEST IT! (2 minutes)
================================================================================

1. Open browser: http://localhost:3001
2. Login as admin
3. Go to Admin Portal → Staff Management
4. Click "Modify" on any staff member
5. Try to change their email or password
6. Click "Change" button next to email/password
7. You should see success messages!

Also test:
- Delete a blog (it should delete images too)
- Check backend terminal for activity logs

================================================================================
TROUBLESHOOTING
================================================================================

❌ Backend won't start?
   → Check backend/.env file exists and has all values filled
   → Make sure port 5000 is not in use
   → Check Firebase credentials are correct

❌ Frontend can't connect to backend?
   → Check VITE_API_BASE_URL in frontend .env
   → Make sure backend is running
   → Restart frontend after changing .env

❌ "Missing required environment variables"?
   → Double-check all values in backend/.env
   → Make sure FIREBASE_PRIVATE_KEY has quotes around it
   → Verify no typos in variable names

❌ "CORS error"?
   → Check FRONTEND_URL in backend/.env matches your frontend URL
   → Restart backend after changing .env

PRODUCTION DEPLOYMENT
================================================================================

When ready for production:

1. Deploy backend to a hosting service:
   - Heroku, Railway, Render, DigitalOcean, etc.
   - Make sure to use HTTPS!

2. Update environment variables:
   - Backend: FRONTEND_URL=https://your-domain.com
   - Frontend: VITE_API_BASE_URL=https://your-backend.com/api

3. Rebuild and deploy frontend

For detailed deployment guide, see:
- BACKEND_IMPLEMENTATION_SUMMARY.txt
- backend/SETUP_GUIDE.txt
