NEXT STEPS - WHAT YOU NEED TO DO
================================================================================

1️⃣ INSTALL BACKEND DEPENDENCIES:
   
   cd backend
   npm install
   
   This will install all required packages.

2️⃣ GET FIREBASE ADMIN SDK CREDENTIALS:
   
   a) Go to: https://console.firebase.google.com/
   b) Select your project
   c) Settings → Service Accounts
   d) Click "Generate New Private Key"
   e) Download the JSON file (KEEP IT SECURE!)

3️⃣ CREATE BACKEND .env FILE:
   
   cd backend
   cp .env.example .env
   
   Then fill in these values from the Firebase JSON:
   - FIREBASE_PROJECT_ID
   - FIREBASE_PRIVATE_KEY (keep the \n characters!)
   - FIREBASE_CLIENT_EMAIL
   
   And add your Cloudinary credentials:
   - CLOUDINARY_CLOUD_NAME
   - CLOUDINARY_API_KEY
   - CLOUDINARY_API_SECRET

4️⃣ UPDATE FRONTEND .env FILE:
   
   Add this line to your frontend .env:
   
   VITE_API_BASE_URL=http://localhost:5000/api
   
   REMOVE this line (if it exists):
   
   VITE_CLOUDINARY_API_SECRET=...  ❌ DELETE THIS!

5️⃣ START THE BACKEND:
   
   cd backend
   npm start
   
   You should see:
   🚀 Enarxi Backend API Server
   📡 Server running on: http://localhost:5000

6️⃣ START THE FRONTEND:
   
   cd ..
   npm run dev
   
   Frontend should connect to backend automatically.

7️⃣ TEST THE INTEGRATION:
   
   a) Login as admin
   b) Go to Staff Management
   c) Try to change a user's email or password
   d) Try to delete a blog
   e) Check backend terminal for logs

================================================================================
TROUBLESHOOTING
================================================================================

❌ "npm is not recognized"
   → Install Node.js from: https://nodejs.org/
   → Restart terminal after installation

❌ "Missing required environment variables"
   → Check backend/.env file exists
   → Verify all variables are filled in
   → Check for typos in variable names

❌ "Firebase Admin SDK initialization failed"
   → Verify FIREBASE_PRIVATE_KEY has \n characters
   → Check quotes around private key
   → Verify project ID and client email are correct

❌ "CORS error from frontend"
   → Check FRONTEND_URL in backend/.env
   → Restart backend after changing .env
   → Verify frontend URL matches exactly

❌ "Cannot connect to backend"
   → Check backend is running (npm start)
   → Verify port 5000 is not in use
   → Check VITE_API_BASE_URL in frontend .env
   → Check firewall settings

❌ "Cloudinary deletion fails"
   → Verify Cloudinary credentials in backend/.env
   → Check API_SECRET is correct
   → Verify public_id extraction works
